お使いいただく手順をご案内します。

「クーポン配布ページ」や 「クリスタルクリーンホームチラシ」からクーポンコードを入手する。

サービスをカートに追加して、 「カート確認・申し込み」ボタンをタップ（クリック）する。

続けてお買い物をする方は「戻る」このままお見積りをされる方は、 「カートを見る」ボタンをタップ（クリック）する。

お見積り内容を確認して、 「お客様情報の入力に進む」ボタンをタップ（クリック）する。

「お客様情報のご入力」画面下部のクーポンコード欄にコピーしたクーポンコードを貼り付ける。

「ご入力内容画面」でクーポン割引が適用されていることを確認し、お見積り依頼を完了する。
