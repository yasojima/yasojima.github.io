第1条（適用範囲）

本ポリシーは、当サービスのウェブサイト、見積りカート、お問い合わせフォーム、お見積り・ご依頼に伴う連絡、清掃サービスの提供およびアフターサポートに関して、当社が取り扱う個人情報に適用します。外部の事業者が提供するサービスについては、当該事業者が定めるプライバシーポリシー等も適用される場合があります。

第2条（取得する情報）

当社は、サービスの利用状況に応じて、次の情報を取得し、または取り扱います。

  1. お客様および連絡先に関する情報：氏名、フリガナ、会社名・団体名、担当者名、メールアドレス、電話番号、郵便番号、住所等。
  2. お見積り・清掃依頼に関する情報：希望するサービスの種類、対象設備・作業箇所、数量、オプション、見積り金額、希望日時・時間帯、作業先住所、建物の種類や設備・汚れの状態、お問い合わせ内容、備考、依頼・対応履歴等。
  3. お客様から任意に提供される情報：電話・メール等での相談内容、清掃箇所の写真（施工対象確認のため）その他、お客様が説明のために提供する資料等。【※写真受付を行う場合の運用を確定のうえ掲載】
  4. サイト利用に伴う情報：アクセス日時、閲覧したページ、アクセス元、IPアドレス、ブラウザ・端末に関する情報、Cookie・ローカルストレージ等の識別子、ブラウザ内に保存されるカート・入力途中の情報等。
  5. 業務上の記録：お見積りの提示内容、予約・訪問・作業に関する連絡履歴、請求・支払状況、苦情・相談への対応履歴等。【※本番運用で保存する範囲を確定のうえ掲載】

当社は、法令で認められる場合を除き、要配慮個人情報を本人の同意なく取得しません。お客様には、サービスの提供に必要のない病歴、個人番号等の機微な情報をお問い合わせ欄等に入力しないようお願いいたします。

第3条（利用目的）

当社は、取得した個人情報を次の目的の達成に必要な範囲で利用します。

  1. お問い合わせ、ご相談、資料請求等への回答とご本人への連絡のため。
  2. 清掃サービスのご案内、希望内容の確認、概算見積り・正式見積りの作成、料金・条件の説明のため。
  3. 清掃箇所、対象設備、訪問先、ご希望日時等の確認、訪問日程の調整、作業準備およびサービスの実施のため。
  4. 申し込み・契約内容の確認、変更・キャンセルへの対応、請求・精算および支払いに関する事務処理のため。
  5. 作業後の確認、アフターサポート、事故・不具合への対応、苦情・ご相談への対応のため。
  6. ご本人確認、不正利用の防止、サイトやシステムの安全確保、障害対応および記録管理のため。
  7. 利用状況の把握、サービスの品質管理、ウェブサイトの改善、問い合わせ対応体制の改善のため。この場合、可能な範囲で個人を識別しない統計情報を利用します。
  8. 法令に基づく義務の履行、権利・利益の保護、必要な調査および紛争等への対応のため。
  9. その他、取得時に本人へ個別に明示し、または適法に公表した目的のため。

※広告・キャンペーン等の案内メールを送信する場合は、当該配信の目的、取得する情報および配信停止方法を別途示し、必要な同意その他法令上の要件を満たす方法で実施します。【※配信を実施する場合のみ掲載】

第4条（取得方法と入力の任意性）

当社は、お客様がフォームに入力した情報、電話・メール等でお知らせいただいた情報、サービスの利用に伴う記録等から個人情報を取得します。フォーム等でご本人から直接取得する場合は、法令に従い利用目的をあらかじめ明示します。個人情報の提供は原則としてお客様の任意ですが、必要な情報が提供されない場合、お見積り、訪問日時の調整、サービスの実施またはお問い合わせへの回答ができないことがあります。

第5条（ブラウザ内への情報保存）

当サービスの見積りカートでは、サービスの選択内容、数量、お客様が入力途中の見積り情報等を、お使いのブラウザのローカルストレージ等に一時保存する場合があります。これらは画面遷移や入力内容の確認・復元などに利用します。現在のカート保存機能には、前回の操作から一定期間（※仕様上の保持期間。例：24時間）以上経過した後の次回アクセス時に、関連データを自動削除する仕組みが組み込まれています。【※実際のプログラムの自動削除時間と一致させて確定してください】共用端末を利用する場合、ほかの利用者から入力途中の情報を閲覧される可能性があります。利用後はブラウザ内の保存データを削除するなど、端末の管理にご注意ください。

第6条（見積り依頼の送信と保存先）

お客様が見積り依頼の送信操作を行う場合、当社は、送信されたお客様情報、選択された清掃メニュー、希望日時、備考等を、依頼の受付・確認・返信・作業準備に必要な範囲で受領し、取り扱います。送信処理には、当社が管理するシステムまたは当社が利用する外部のシステム・メール配信サービスを使用する場合があります。【※本番システム稼働前に、実際の送信先サーバー・メール受付システム・保管期間・委託先を確定し、実運用と一致させてください】

第7条（Cookie等および外部送信に関する情報）

当サービスは、サイトの適切な表示、言語切替、入力補助、不正送信防止およびアクセス状況の確認等のため、Cookie、ローカルストレージ、その他の技術を用いて端末情報を取得・送信する場合があります（電気通信事業法に基づく外部送信規律への対応）。

組み込まれている主な外部ツール、送信される情報、送信先事業者および利用目的は以下のとおりです。

  1. Google Fonts / Google翻訳（Google LLC）
    • 送信情報：IPアドレス、閲覧・端末情報、選択言語・翻訳対象テキスト
    • 目的：ウェブサイト上のフォント表示および言語翻訳機能の提供
  2. Cloudflare Turnstile（Cloudflare, Inc.）
    • 送信情報：IPアドレス、ブラウザ・端末情報、操作ログ等
    • 目的：ボットや不正送信（スパム）の防止および安全確保
  3. Yahoo! JAPAN 郵便番号検索機能（LINEヤフー株式会社）
    • 送信情報：入力された郵便番号
    • 目的：郵便番号からの住所入力補助
  4. ウェブサイト配信基盤（GitHub, Inc. / GitHub Pages）
    • 送信情報：IPアドレス、アクセスログ、端末情報
    • 目的：ウェブサイトのコンテンツ配信および安定運用

Cookie等はブラウザの設定から削除・制限できますが、設定によってはサイトの一部機能を利用できなくなる場合があります。なお、今後アクセス解析ツール（Google Analytics等）や広告マーケティングタグを導入する場合は、事前に送信情報・利用目的等を本条に追記・開示します。

当社は、法令で認められる場合を除き、あらかじめ本人の同意を得ることなく、個人データを第三者に提供しません。ただし、法令に基づく場合、人の生命・身体・財産の保護に必要で本人の同意を得ることが困難な場合、その他個人情報保護法上認められた場合は、この限りではありません。委託、事業承継その他法令により第三者提供に該当しないものとして扱われる場合については、関係法令に従って取り扱います。

第9条（業務委託と協力会社への情報提供）

当社は、メール送信、システム運用・保守、見積り受付、顧客対応、日程調整、清掃作業等について、必要な範囲で業務を委託する場合があります。その際は、委託先に必要な情報のみを取り扱わせ、契約、権限管理、取扱状況の確認その他必要かつ適切な監督を行います。清掃を実施する店舗・協力会社等が当社とは別の事業者である場合は、単なる業務委託か、第三者提供か、共同利用かを実態に即して区分し、必要な措置および同意取得を行います。【※実際の運営体制を確定のうえ掲載】

第10条（外国にある事業者による取扱い）

当社は、クラウドサービス、外部インフラ（GitHub Pages等）、セキュリティ・認証サービス（Cloudflare等）、翻訳・フォントサービス等の利用に伴い、外国にある事業者のサーバー等で個人データまたは関連する技術情報が取り扱われる場合があります。当社は、利用する外部サービスの提供国・地域における個人情報保護制度を把握したうえで、通信の暗号化（HTTPS）やアクセス制限等の適切な安全管理措置を講じます。【※外国にある具体的な保管先や委託先が確定した場合は、その国名等を追記してください】

第11条（個人データの安全管理措置）

当社は、個人データの漏えい、滅失、毀損、不正アクセス等の防止のため、以下のとおり必要かつ適切な安全管理措置を講じます。

  1. 基本方針・規律の整備：本ポリシーを定め、取得・利用・保存・削除等の各段階における取扱方法を周知徹底します。
  2. 組織的安全管理措置：個人データの取扱責任者を明確化し、漏えい等の事故またはその兆候を把握した場合の報告連絡体制を整備します。
  3. 人的安全管理措置：従業者に対して個人情報の適切な取扱いに関する教育・周知を行い、秘密保持に関する取決めを講じます。
  4. 物理的安全管理措置：個人データを取り扱う機器や記録媒体の盗難・紛失を防止するための管理（施錠管理、パスワード設定等）を行います。
  5. 技術的安全管理措置：アクセス権限の最小化・管理、通信の暗号化（SSL/TLS）、外部からの不正アクセスを防止するセキュリティ対策（Cloudflare等の導入）を実施します。

個人データの漏えい等が発生した場合は、事実関係の確認、被害拡大の防止、再発防止に取り組み、法令上必要な場合には個人情報保護委員会への報告およびご本人への通知を行います。

第12条（保存期間および削除）

当社は、取得した個人情報を利用目的の達成に必要な期間、または法令・契約等に基づき保存が必要な期間に限り保管し、不要となった情報は復元不可能な方法で速やかに削除・廃棄します。ただし、法令に基づく保存義務がある場合や紛争・請求への対応に必要な場合は、必要な範囲で保存することがあります。

第13条（保有個人データの開示・訂正・利用停止等）

ご本人は、法令に従い、当社が保有するご自身の保有個人データについて、利用目的の通知、開示、訂正・追加・削除、利用停止・消去、第三者提供の停止等を求めることができます。また、法令上認められる場合、第三者提供記録の開示を請求できます。ご希望の場合は第15条の窓口にご連絡ください。ご本人確認を行ったうえで、法令に従い迅速に対応します。【※開示等手続きにおいて手数料を徴収する場合は、その金額および支払方法を確定して追記してください】
